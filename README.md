# Personal Finance Manager

Desktop приложение для учета личных финансов.

## Функциональность

- Учет доходов и расходов
- Категоризация операций
- Расчет текущего баланса
- Аналитика по категориям
- Автосохранение в CSV-файл

## Структура проекта

```
personal-finance-app/
├── finance_classes.py    # Классы Transaction, Category, FinanceManager
├── finance_gui.py        # GUI на Tkinter
├── transactions.csv      # Хранилище данных
├── requirements.txt
└── README.md
```

## Классы

- `TransactionType` — `Enum` с типами операций (`Доход` / `Расход`)
- `Category` — категория операции (название и тип)
- `Transaction` — финансовая операция (сумма, категория, дата, описание)
- `FinanceManager` — управление списком операций, расчет баланса и
  аналитики, чтение/запись CSV-файла

## Запуск

1. Установите Python 3.7+
2. Запустите: `python finance_gui.py`
3. Добавляйте операции через форму вверху
4. Просматривайте аналитику через кнопку "Аналитика"

## Формат данных

`transactions.csv` хранит операции в формате CSV с колонками:

```
Amount,Category,Type,Date,Description
```

Файл автоматически создается при первом сохранении и загружается при
запуске приложения.
